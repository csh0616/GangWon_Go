## 2. LLM 가중치 출력 일관성 검증 (PRD 3.5절 액션 아이템)

> 목적: 같은 의도의 자유텍스트를 여러 번 넣었을 때 LLM이 만드는 가중치가 얼마나 흔들리는지 확인.
> **판정 기준(PRD 3.5절)**: 카테고리별 최대값-최소값(편차)이 **0.2를 넘으면** 이산 단계
> (낮음/보통/높음/매우높음, 고정값 0.2/0.5/0.75/1.0)로 낮추는 걸 백엔드팀과 상의 (`API_CONTRACT.md` 5장).

| ID | 입력(free_text) | 반복 횟수 | 관찰한 편차 | 판단 |
|---|---|---|---|---|
| [예시] T-101 | "등산 위주로 여유롭게 다니고 싶어요" | 5회 | nature_hiking: 0.75~0.90 (편차 0.15) | 0.2 미만 → 허용 범위로 판단 |

## 5. 데모 리허설 스크립트 (PRD 11.5절, 3주차)

> 목적: 실제 데모 발표 순서를 정해진 대사로 고정해서 리허설마다 흔들리지 않게 함.

1. [예시] 게스트로 접속 → 인제/홍천/평창 중 선택 → 날짜/인원/관계 입력 → 자유텍스트로 "등산이랑 온천"
2. [예시] 코스 생성 결과 확인 (3초 이내) → "코스 저장" 클릭 → Google 로그인
3. [예시] 저장 완료 화면 → 강제 트리거 버튼(weather) 클릭
4. [예시] 대안 일정 모달 확인 — 문구가 팀이 확정한 리허설 문구("비가 옵니다, [실제 시드 POI명] 대신
   [실제 대체 POI명]로 변경할까요?" — 8장에서 확정한 실제 장소명 사용)와 정확히 일치하는지 재확인
5. [예시] 언어 전환(영→중) → 지도/문구 정상 전환 확인
6. [예시] SOS 버튼 클릭 → tel:119 확인 (로그인 여부 무관하게 되는지 재확인)
